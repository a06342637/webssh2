会让远端按物理像素输出，画面更锐利，但带宽和解码开销明显增加。
开启后画面独占整个窗口，把鼠标贴到屏幕顶边停一下，工具栏会滑出来。关掉则常驻显示。
中转不等于加速。多一跳只在直连线路本身劣质（高丢包、绕路）时才可能变快。 另外 SSH 跳板会把 RDP 的 TCP 套进另一层 TCP，丢包时两层重传互相叠加，反而可能更卡—— 线路质量好的时候优先直连。
浏览器读取剪贴板需要你在弹出的权限提示里放行，否则只有「远端 → 本地」方向可用。
关闭后走扫描码，游戏和快捷键更准；开启后中文/表情等直接输入更方便。
依赖浏览器的 Keyboard Lock 能力，可让 Alt+Tab、Win 键等发送到远端。部分浏览器不支持。

                            普通用户忘记密码
                            请联系管理员。管理员登录后可在「账号管理」中找到该用户并重置密码。
                        

                        

                            管理员忘记密码（Docker Compose）
                            在项目目录执行下面的命令；用户名会优先使用上方已填写的用户名。
                            

                                WEBSSH_ADMIN_USER=admin WEBSSH_ADMIN_PASSWORD='请替换为新密码' WEBSSH_ADMIN_RESET=true docker compose up -d --force-recreate
                                
                            

                            重置成功后将 WEBSSH_ADMIN_RESET 改回 false，或删除该项，避免以后重启时重复重置。
